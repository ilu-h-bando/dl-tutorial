# ファインチューニング（LoRA）ハンズオン教材

[transformer/](../transformer/) の [TF01](../transformer/TF01_tiny_gpt_waka.ipynb)（和歌を詠む1ブロックのGPT）を**事前学習済みモデル**として使い、
**本体の重みを固定したまま、小さな追加の行列（LoRA）だけを学習して振る舞いを変える**チュートリアルです。
PyTorchやTensorFlow、学習済みモデルは使いません（`numpy`・`matplotlib` のみ）。Google Colabのボタンからブラウザで実行できます。

## TF04 で体験すること

```text
① 事前学習：和歌 約5,600首で、全部の重み（72,192個）を学習（TF01と同じ）
② 語彙を広げる：俳句にだけある文字30種（濁点の字・ゃゅょゎっ・ん）を、Embedding表と出力層に追加
③ LoRA：Wq・Wv に W' = W + (α/r)·A·B（r=4）を付け、A・B と新しい文字の行・列だけを芭蕉の句で学習
④ 比べる：同じ書き出しの5音から、LoRAの前・後・外したときで、詠んだ詩の形（和歌／俳句）の割合を数える
```

- **LoRA**：学習済みの `W`（64×64）は変えず、`A`（64×4）と `B`（4×64）だけを学習します。`B` を0で始めるので、学習前は元のモデルと同じです。
- **語彙の拡張**：和歌の読みには濁点や「ん」がありません。新しい文字は語彙の後ろに足し、入力側は元の字（「が」←「か」など）のベクトルを写し、出力側は0から始めます。
- **元に戻せる**：学習後に `A・B` を取り除くと、和歌を詠むモデルに戻ります。本体の重みが変わっていないこともノート内で確かめます。

## 実行する

1. 上表のColabボタンで開き、「ランタイム > すべてのセルを実行」を選びます。
2. 和歌はWikisourceから、俳句は本フォルダの `芭蕉俳句全集.txt` をGitHubから取得します（インターネット接続が必要です）。
3. 事前学習は手元のCPUで約1分40秒、LoRAの学習は約45秒でした。事前学習の結果は `tf04_base_waka.npz` に保存し、次回は読み込みます。
4. ノート途中の入力欄で、最初の5音（ひらがな、濁点あり）を入れると、LoRAなし（和歌）とLoRAあり（俳句）の両方で続きを詠みます。

NumPyのCPU実装です。ColabでGPUを選択しても、このコードはGPUを使いません。

## 実行結果の目安

作成者のPCで1回実行した結果です（SEED=0、LoRAは Wq・Wv、r=4、1,500ステップ）。環境と乱数で変わります。

俳句の検証用の句（学習に使っていない94句）の最初の5音から、各2回詠ませた形の割合：

| モデル | 俳句（5-7-5） | 和歌（5-7-5-7-7） | その他 |
|---|---:|---:|---:|
| LoRA 学習前 | 0% | 96% | 4% |
| LoRA 学習後 | 76% | 0% | 24% |
| LoRA を外す | 0% | 88% | 12% |

- 学習する重みは LoRA 1,024個＋新しい文字の行・列 3,840個 ＝ 4,864個（事前学習モデルの6.7%）です。
- 「その他」の多くは、途中で音数が1つずれたものです。1ブロック・約850句の小さな学習なので、意味の通る句にはなりません。

## 芭蕉俳句全集.txt

- 1行に1句、`原文<TAB>読み（TAB 印）` の形です（UTF-8）。読みは5・7・5ごとに `／` で区切っています。
- 印：なし＝5-7-5で学習に使う句（944句）、`字`＝字余り（183句）、`△`＝読みに自信がない句（195句）。TF04は印なしの句だけを使います。
- 読みは歴史的仮名遣いで、濁点あり、拗音（ゃゅょゎ）だけ小書きにしています。
- **読みは AI（Claude Opus 5.5）が付けたもので、誤りを含む可能性があります。** 人による確認は一部のみです。
